--- durexForth: turnkey images ---
[ ] SAVE-PACK ( "name" -- ) - save a packed turnkey image that runs
    START on load. Waiting on a DECISION, not on code: an X816 program
    image is magic plus an entry at $01:0004 (X816_core doc/KERNEL.md),
    and a packed Forth spans banks $01-$04 with its headers growing down
    from $01:FEFF - so what a turnkey image contains, and how the kernel
    is told to run it, belongs in the kernel repo first.
[-] SAVE-PRG ( "name" -- ) - save a plain runnable PRG image.
[-] SAVE-FORTH ( "name" -- ) - save the raw $0801..top memory range as a PRG.
[ ] TOP ( -- addr ) - top of dictionary space. On the C64 this was one
    number below the I/O area; here the headers grow DOWN from $01:FEFF
    while the code grows UP through banks $01-$04, so "the top" is two
    numbers and which one it means depends on SAVE-PACK above.
[ ] TOP! ( addr -- ) - move the dictionary down to addr, packing it
    against the code. Same dependency.
[x] START ( -- addr ) - the startup-word pointer executed at boot (turnkey hook).
