=== SYSTEM - System and environment ===

[x] ENVIRONMENT? ( addr len -- false | i*x true ) - query a system attribute.
[x] HELP ( "topic" -- ) - always resident. HELP alone shows the topic
    index; HELP STRING shows one page. The pages live in /HELP on the card
    and are read with the ordinary file words, so a card without them says
    so rather than hanging.
    Output pauses every 22 lines: any key continues, ESC or Q stops.
    Card names are the topic TRUNCATED TO EIGHT characters and uppercased -
    the kernel's FAT32 reader skips long filenames, so HELP ARITHMETIC
    reads /HELP/ARITHMET.TXT. All forty topics truncate uniquely, and both
    card builders fail loudly if that ever stops being true.
[x] AUTORUN - if a file named AUTORUN exists on the SD card, it is
    INCLUDEd at every boot before the banner. Not a word: it is a boot
    hook in base.fs. A missing AUTORUN is silent (-37 is caught); any
    OTHER error it raises is reported, because a swallowed one looks
    exactly like a machine that stopped for no reason.
[x] BYE ( -- ) - reset the machine through the SMC, the same command
    Ctrl+Alt+Del raises. There is no ROM to cold-start back into, so this is
    a real reset and not a return to a monitor. NEEDS SYSTEM.
[x] VER ( -- n ) - version number, high byte x 256 + low. VER .
[x] X816 / X16 / C64 / F256 ( -- flag ) - platform flags. X816 is true and
    X16 IS FALSE: the hardware is X16-shaped - the same VERA, VIAs and YM -
    and is not an X16, so code testing X16 to decide whether a KERNAL exists
    gets the right answer and does not call into nothing.
[-] USR ( i*x addr -- j*x ) - call machine code at addr. NOT HERE, and not
    for want of trying: durexForth carries an assembler, so machine code is
    an ordinary word - `code myword ... end-code` - which is more than USR
    offered and gets the calling convention right. Words are entered by jsl
    and leave by rtl, registers are 16 bits, and X is the data stack pointer
    and must come back untouched; USR's `lda #7 / rts` example breaks all
    three.
[x] RANDOM ( -- n ) - a 32-bit xorshift, seeded once from the free-running
    millisecond timer. The X16 took this from a KERNAL entropy call; there
    is none here. RANDOM8 and RANDOM16 mask it down.
[x] RND ( u -- n ) - pseudo-random number in 0..u-1 (BASIC-style). 6 RND 1+
    -> a die roll.
[x] IRQ ( xt -- ) - arm a Forth word to run once per frame; 0 IRQ disarms.
    In base.fs, no module needed. The handler must be short, stack-neutral,
    must not THROW and must not enable interrupts. See HELP ADVANCED for
    LINE-IRQ and SPRCOL-IRQ. ' TICK IRQ
[x] FREE ( -- ) - print the free dictionary space.
[x] WORDS ( -- ) - list the words in the context wordlist.
--- durexForth ---
[x] NOTFOUND ( caddr u -- ) - handler for an unrecognised word (prints the name + "?").
[x] IOABORT ( ioresult -- ) - if ioresult is nonzero, print a message and THROW -37.
--- X816 ---
[x] EMU-EXIT ( status -- ) - stop the X816 EMULATOR with an exit status, so a
    test harness gets its verdict instantly. Open bus on real hardware: the
    word is a harmless no-op there (callers put a hardware fallback after it).
[ ] STOP ( clk -- ) - print the time elapsed since TI (TIMER.FTH; pairs with TI ( -- clk ); named like BASIC TI - not START, which is the turnkey boot cell).
