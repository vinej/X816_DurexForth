=== KERNAL - call any KERNAL / ROM routine ===

[ ]   SYSCALL ( a x y addr -- a' x' y' )   call the routine at addr in KERNAL bank
     0 with .A/.X/.Y loaded, returning the callee's .A/.X/.Y. Reaches the whole
     KERNAL API (GRAPH_*, console_*, MEMTOP, ...). ROM-safe (routes via jsrfar).
     Example:  65 0 0 $FFD2 SYSCALL   prints "A" (CHROUT).

The X16's CHARSET ( n -- ) selected one of a dozen 8x8 fonts in ROM
(1 = ISO, 2 = PET upper/graphics, ... 12 = Katakana). It is deliberately
NOT listed here as a checkbox entry: this machine has no charset ROM, so
that word cannot exist - while a CHARSET that DOES exist lives in VIDEO,
and an unticked box under this name would read as a lie either way. The
X816 keeps the name for the same job done the way the hardware works:
CHARSET ( vaddr -- ) points VERA layer 0 at 2 KB of tile data, with the
font words beside it. HELP VIDEO.

(Do not start a prose line in these files with a bracket pair. The
checkbox tracker is parsed, and a wrapped sentence beginning "[ ] here"
became an entry claiming HERE was missing.)

Common KERNAL entry points for SYSCALL: CHROUT $FFD2, CHRIN $FFCF,
GETIN $FFE4, PLOT $FFF0, SCREEN_MODE $FF5F. See the X16 Programmer's
Reference for the full jump table.

--- durexForth: low-level channel I/O (IO.FTH) ---
[ ] CHKIN ( file# -- ioresult ) - make an open logical file the input device (KERNAL CHKIN).
[ ] CHKOUT ( file# -- ioresult ) - make an open logical file the output device (KERNAL CHKOUT).
[ ] CHRIN ( -- char ) - read one byte from the current input (KERNAL CHRIN/BASIN).
[ ] CLRCHN ( -- ) - restore input/output to the console (KERNAL CLRCHN).
[ ] READST ( -- status ) - read the I/O status byte (KERNAL READST).

--- durexForth ---
[ ] BCALL ( a x y bank addr -- a3 x3 y3 ) - call the routine at addr in ROM/RAM bank, passing/returning .A/.X/.Y.
