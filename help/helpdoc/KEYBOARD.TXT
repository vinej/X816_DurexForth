=== KEYBOARD - keyboard input ===

[x]   KEY    ( -- char )   wait for a key, return its code (standard Forth; echoes).
[x]   KEY?   ( -- flag )   true if a key is waiting (non-destructive peek).
[ ]   GETKEY ( -- char )   block until a key is pressed, return its PETSCII code.
[ ]   KEYMAP ( c-addr u -- )   set the keyboard layout (core).  S" DE-DE" KEYMAP

GETKEY and KEYMAP are in asm/sysx.asm, which durexforth.asm does NOT
assemble: each called a KERNAL entry ($FED2 for KEYMAP) and there is no
KERNAL here. KEY and KEY? go through the kernel console instead, and are
the two that work.

CHARSET used to sit here as a third. It is DONE, but it moved to VIDEO
and changed shape on the way: there is no charset ROM, so it takes a VRAM
address rather than a ROM number. HELP VIDEO.

Poll without blocking:
  : POLL  KEY? IF GETKEY ... THEN ;
