=== AUDIOFM - PSG and YM2151 ===

Two synths: the VERA PSG, 16 voices 0-15, and the YM2151 FM chip, 8
channels 0-7. Both are on this machine.

THE NOTE API IS NOT. PSGNOTE, FMINIT, FMINST, FMNOTE and the play-string
words were the X16 ROM's audio driver - a note table and 163 instrument
patches living in ROM. There is no such ROM here, so they are unticked
and they do not exist: porting that driver is a job of its own, and a
word that existed and did nothing would be worse than its absence.

What IS here is every register the chips have. The PSG voice words below
are direct VRAM writes; for the YM2151 see HELP AUDIOYM, and for sampled
sound HELP AUDIOPCM.

VERA PSG - voice registers, 4 bytes each at VRAM $1F9C0:
[x]   PSGINIT  ( -- )              silence and zero all 16 voices
[x]   PSG!     ( value n -- )      write PSG register n (0-63) directly
[x]   PSG@     ( n -- value )      read one back
[x]   PSGFREQ  ( freq voice -- )   set the raw 16-bit frequency word
[ ]   PSGNOTE  ( note voice -- )   play a packed note (0 = release)
[x]   PSGVOL   ( vol voice -- )    volume 0-63, and it sets BOTH channels -
                               so it overrides an earlier PSGPAN
[x]   PSGWAV   ( wave voice -- )   waveform 0-3 (pulse/saw/triangle/noise);
                               keeps the pulse width in the same byte
[x]   PSGPW    ( pw voice -- )     pulse width 0-63, keeping the waveform.
                               NOT optional for waveform 0: the renderer
                               emits a high sample only while phase>>10
                               is <= pw, so the 0 that PSGINIT leaves is
                               a 1-in-64 duty cycle - a thin click, not a
                               tone. 32 is a square wave. Saw and triangle
                               use pw as an XOR on the phase instead and
                               are full-strength at any width.
[x]   PSGPAN   ( pan voice -- )    stereo pan (1=left 2=right 3=both);
                               keeps the volume in the same byte
[ ]   PSGPLAY  ( c-addr u voice -- )   play a play-string (blocking)
[ ]   PSGCHORD ( c-addr u voice -- )   play a chord string (blocking)

YM2151 FM:
[ ]   FMINIT   ( -- )              init the chip + load default patches
[ ]   FMINST   ( inst channel -- ) select an instrument patch 0-162
[ ]   FMVOL    ( vol channel -- )  channel volume 0-63
[ ]   FMNOTE   ( note channel -- ) play a packed note (0 = off)
[ ]   FMFREQ   ( freq channel -- ) play a raw frequency in Hz (17-4434)
[ ]   FMDRUM   ( drum channel -- ) play a drum sound (25-87)
[ ]   FMVIB    ( speed depth -- )  global vibrato (0-127)
[ ]   FMPAN    ( pan channel -- )  stereo pan (1=left 2=right 3=both)
[ ]   FMPLAY   ( c-addr u channel -- )  play a play-string (blocking)
[ ]   FMCHORD  ( c-addr u channel -- )  play a chord string (blocking)

A beep, with no driver involved:
    PSGINIT  1181 0 PSGFREQ         \ ~440 Hz
    32 0 PSGPW  0 0 PSGWAV          \ square wave - see PSGPW
    63 0 PSGVOL                     \ ...and it sounds
    0 0 PSGVOL                      \ silence again

One voice at full volume is about an eighth of the output's range, so a
single PSG note is quiet by design: the mix leaves headroom for sixteen
voices plus PCM and the YM2151. Use several voices, or the YM, to fill
it. A sawtooth is the loudest single waveform - try 1 0 PSGWAV.
