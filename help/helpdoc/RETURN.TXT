=== RETURN - Return stack and loop index ===

[x] >R ( x -- ) (R: -- x) - move an item to the return stack.
[x] R> ( -- x ) (R: x -- ) - move it back.
[x] R@ ( -- x ) - copy the top of the return stack.
[x] RDROP (R: x -- ) - drop the top of the return stack.
[x] 2>R ( x1 x2 -- ) - move a pair to the return stack.
[x] 2R> ( -- x1 x2 ) - move a pair back.
[x] 2R@ ( -- x1 x2 ) - copy a pair.
[x] I ( -- n ) - index of the innermost DO loop.
[x] J ( -- n ) - index of the next-outer DO loop.
--- X816 return-ADDRESS juggling (stage C) ---
A return address on this machine is THREE bytes, not two: stage C threads
every call as jsl/rtl across banks $01-$04. >R and R> move whole 32-bit
cells and are wrong for addresses, so the "R> ... >R ;" idiom - LITS,
DOES>, (?DO), (+LOOP), UNLOOP - uses the pair below instead. They replace
stage B's RW>/W>R, which moved 16 bits and dropped the bank.
[x] RL> ( -- addr ) (R: ret24 -- ) - pull the caller's return address as a
    flat cell; the bank rides in bits 16-23, so it is an ordinary address.
[x] L>R ( addr -- ) (R: -- ret24 ) - push a flat cell back as a 3-byte
    return address. Pair every RL> with one, in the same word.
    A stray RTS ($60) where an RTL ($6B) belongs leaks the bank byte and
    detonates one return later, at a distance that looks like anything
    except its cause.
